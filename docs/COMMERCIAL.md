# Commercial roadmap (not shipped)

The public MIT community edition includes offline plan inspection and synthetic SQLite benchmarks. These useful features remain free under the public license.

Potential paid products must provide new value **not** represented as a requirement to use the MIT code:

| Hypothetical edition | Suggested initial test price | Additional features to build |
|---|---:|---|
| Desktop Pro | $19 one-time | Signed Windows installer, side-by-side multi-plan history, advanced report formats, batch jobs and customer support |
| Cloud/Team | $9 per month to start | Encrypted shared reports, scheduled regression checks, user roles and retention policies |

None of the features above is implemented yet. The prices are hypotheses, not validated customer demand or guaranteed income. Support, payment processing, signed executables, and operational costs must be budgeted.

Production deployments serving multiple customers would require authentication, database isolation, billing, incident monitoring, penetration testing and a documented retention policy.

Public repository is purposely separate from any proprietary licensing service and other private projects.
